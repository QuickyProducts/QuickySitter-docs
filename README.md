# QuickySitter documentation

Source for the QuickySitter&trade; documentation website at <https://quickyproducts.github.io/QuickySitter-docs/>.

QuickySitter LSL scripts live in the separate repository <https://github.com/QuickyProducts/QuickySitter>.

## Building locally

```bash
bundle install
bundle exec jekyll serve
# open http://127.0.0.1:4000/QuickySitter-docs/
```

The site uses the [Documentation Theme for Jekyll](https://github.com/tomjoht/documentation-theme-jekyll) by Tom Johnson (MIT).
