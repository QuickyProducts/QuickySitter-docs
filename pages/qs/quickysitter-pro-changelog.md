Customer-facing changes only. Each entry is tagged **Fix** (bug fix), **Feature** (new), or **Base** (groundwork shipped ahead of a separate feature). Routine internal/technical changes aren't listed. Newest version on top.

Entries without an edition marker apply to **both** editions. **Creator Edition** marks what only the creator kit does.

## Version 1.28

- **Feature · Creator Edition**: Remote authoring. Type `/5 animesh` next to a piece (within 5 m) and you build its animesh scene without sitting down: the piece's own pose menu opens, you pick the pose to build, fill the seats with dummies, and move each one with your Quicky HUD while you walk around and look at it from outside. The HUD works as it does when seated: the arrows move, `SELECT` picks which dummy they move, `MENU` returns to the pose menu, `RESET` puts one back, and every change is saved as the pose default straight away. `[ADJUST]` in the pose menu leads to the session's own page with `[ANIMESH]`, `[HELPER HUD]`, `[DUMP]` and `[DONE]`. `[HELPER HUD]` hands you a HUD if you are not wearing one and takes it back when you finish, and `[DUMP]` rebuilds the `AVpos` once you are happy. `[DONE]` ends the session and clears the dummies, and it is the only thing that does: walking off, teleporting away, logging out or sitting down end the session but leave the scene standing, so a group setup survives an interruption. Picking a different pose keeps the dummies on seats that pose does not use, which is how you judge two solo poses against each other. Who may open a session follows the Adjust access level from `[SECURITY]` (or `/5 adjust owner|group|all`), so building from a second account on furniture the store account owns works the same way it already does for the seated tools; on the default setting it stays owner-only. The two modes divide the work: **sit** to create poses and to judge how one feels on you, **stand** to build and position a couple or a group and see it from outside. Sitting down during a session hands you straight to the seated tools, standing up and typing `/5 animesh` brings you back. Needs the matching QuickySitter update (`[QS]prop`).
- **Feature · Creator Edition**: The `[SHOWCASE]` mode in the `[ANIMESH]` menu is gone. It existed so a staged display would survive you standing up; Remote authoring builds the same display without anyone sitting down at all, which is what it was working around. Dummies clear when you stand up from the piece, and a visitor who sits on a staged seat frees it again, so a display piece is set up with `/5 animesh` and finalized as usual.
- **Fix**: The HUD screen position set in the `hudconfig` notecard (the optional fourth field, `HUDOFFSET`) now actually places the HUD there. The value was read and delivered correctly all along, but the HUD never applied it, ever since the field was introduced, so it looked like the setting was simply ignored. The offset is applied every time the HUD attaches, and changing it takes effect the next time the HUD is fetched. Requires the updated QuickyHUD object (`hudmatrix`/`hudcontrol`) in the furniture.
- **Fix**: Updating a whole region full of furniture no longer stops partway. On a large build the updater could run out of working memory in the middle of its push round and stop, and because the pieces it had already reached were part-way through the change, some of them stopped answering the next attempt. It now works in rounds of a size it can finish, tells you how many pieces are still waiting, and leaves the update box standing so the next click carries on where it left off. Nothing has to be found and repaired by hand.
- **Fix**: Furniture protected with an ItsNOTMine plate is recognised in one more of its variants, so the installer stops treating it as an ordinary piece and the plate keeps working after the update.

## Version 1.27

*New names from this release. **QuickySitter** is the sitter engine on its own. **QuickySitter Pro (Creator Edition)** is the kit you build and sell furniture with, and **QuickySitter Pro (Personal Edition)** is the same system for your own furniture. Both editions were previously sold as "QuickyHUD + QuickySitter". The HUD itself keeps its name, QuickyHUD.*

*1.27 is currently available as the **Personal Edition** only. The Creator Edition release of 1.27 is still being prepared; creators stay on 1.26 until it ships.*

- **Feature**: The HUD's arrow controls are now also available as a menu, for sitters who are not wearing a HUD. The `[POSE]` entry in the furniture's `[ADJUST]` menu opens an arrow pad instead of the classic dialog: the same camera-relative directions as the HUD, three step sizes, a Move and a Rotate page, and every press is saved right away. Each sitter gets their own pad, so several people can adjust at the same time. The update brings the new script along, there is nothing to install by hand; furniture that has not been updated keeps the classic dialog. Needs the matching QuickySitter update (`[QS]sitB`) and the QuickyHUD scripts in the furniture.
- **Feature · Creator Edition**: Finalizing a piece (`/5 cleanup`, or `[FINALIZE]` in the `[ANIMESH]` menu) now checks the permissions of the HUD scripts that stay in it and tells you if `[QS]hudproxy` or `[QS]hudadmin` are not copy-only for the next owner, which is what the licence agreement requires. It only tells you: nothing is changed and nothing is removed, so you can correct it in Edit > Contents before you hand the piece out. The two scripts inside the HUD object cannot be checked this way, because no script can read another object's contents.
- **Feature**: One click updates everything, including furniture that still runs the old AVsitter-era QuickyHUD. The updater now delivers its installer into each piece by itself and finishes the job a few seconds later without a second click. Until now those pieces had to be found one by one and the installer dragged into each of them, and pieces you have no modify rights on could not be reached at all.
- **Fix**: Old Quicky furniture is now converted completely instead of half. Previously an update installed the new scripts but left the AVsitter ones in place next to them, because only the installer can replace them and it was not present during a normal update. Affected pieces are repaired by the next update, no matter which state they are in.
- **Fix**: Updating furniture that still runs the older QuickyHUD (the AVsitter-era version) now finishes the job. Its leftover settings are converted instead of being left in a form the new scripts cannot read, so the `[HELPER HUD]` entry actually appears in the furniture's `[ADJUST]` menu rather than silently staying away. The old pose buffer is cleared in the process: personal position adjustments that were saved with the old HUD are not carried over and have to be set again. Your poses and positions (`AVpos`) are untouched.
- **Fix**: The installer now says what it is about to do before you click. When it lands in furniture that still has AVsitter, it tells you that those scripts will be replaced and that the installer cannot undo it afterwards.
- **Fix**: A Personal Edition update box can no longer convert furniture built with the Creator Edition. Until now, running a Personal Edition updater on your build region silently replaced the scripts in your own creations with copy-only ones, and the piece could no longer be sold, usually discovered at sale time. Such pieces now refuse that update with a chat message naming the Creator Edition updater instead. The old shortcut of deliberately "downgrading" a piece with the Personal Edition box is retired with this.
- **Fix**: More headroom for the HUD on busy furniture. The script that keeps track of who is sitting needs more memory with every occupant, and on a full multi-seat piece it could run out and stop, taking the HUD's controls with it. The settings menu has moved into the neighbouring script, which does not grow with the sitters, and that leaves the tracking with more room than in any previous version. The menu itself looks and works exactly as before. `[QS]hudproxy` and `[QS]hudadmin` have to be updated together.

## Version 1.26

- **Feature**: Sitters are no longer given a HUD they did not ask for. The new default attach mode `menuplus` leaves the HUD detached and instead puts a `💠 POSE HUD` entry into the furniture's `[ADJUST]` menu, so whoever wants it presses once and gets it, and pressing again takes it off. Auto-attach was never a design decision, it is what the HUD inherited from its days as an AVsitter plugin, where nothing else was possible. It also meant a permission prompt on every single sit wherever the AVsitter Experience is not available. Furniture that should keep attaching automatically needs `ATTACHMODE` set to `auto` in its `hudconfig` notecard; `menu` (no auto-attach, you place the button yourself in `AVpos`) is unchanged.
- **Feature**: The `[QUICKYHUD]` entry in the furniture's `[ADJUST]` menu is now called `[HELPER HUD]`: it is the HUD counterpart of `[HELPER]`, and the name now says what it does. Requires the matching QuickySitter update.
- **Feature**: ADJUSTMODE is now entered in one place only: the furniture's `[ADJUST]` menu (`[HELPER HUD]` entry). The "Switch ADJUSTMODE" entry in the HUD settings dialog is gone; it dated from the HUD's early days as a stand-alone AVsitter plugin and was a second, separately guarded door into the same mode. Leaving ADJUSTMODE works as before via `[DONE]`/`[ADJUST OFF]` in the pose menu, and it still switches off automatically on stand-up. On plain AVsitter furniture (without QuickySitter) ADJUSTMODE is no longer reachable.
- **Feature**: The "Quicky HUD" furniture menu button is now a toggle: press it while you are already wearing the HUD and the HUD detaches; press it again and it comes back. Until now the button could only attach, and removing the HUD needed right-click > Detach. The pose menu re-opens by itself once the HUD has been attached or removed.
- **Fix**: Leaving ADJUSTMODE (`[DONE]` or automatically on stand-up) now also removes the HUD that `[HELPER HUD]` auto-attached for the adjustment ("menu" attach mode): it no longer lingers in personal-adjust mode nobody asked for. A HUD you started yourself via the menu button stays on, exactly as before.
- **Fix**: Seat swapping no longer silently removes the HUD in "menu" attach mode: sitters who were wearing one before the swap get it re-attached automatically, everyone else stays HUD-free as before.
- **Fix**: If another script in the furniture clears its stored settings, the Quicky HUD now recovers by itself instead of stopping for good. You are told once that it happened. Pose positions and personal adjustments that were stored there are still lost and need re-saving.

## Version 1.25

*The creator product is now called **QuickySitter Pro** (formerly "QuickyHUD Creator"). The HUD itself keeps its name and is one tool in the kit among others. From this release the kit and the QuickySitter engine share one version number: QuickySitter jumps from 1.04 to 1.25 to meet the kit.*

- **Feature**: Fresh builds start sittable: installing into an empty prim now also delivers a starter `AVpos` notecard (one seat, built-in sit animation), so the furniture works immediately. A repair run heals a piece whose `AVpos` was accidentally deleted the same way. An existing `AVpos` is never touched: the starter is only delivered when no notecard exists at all.
- **Fix**: Update safety for notecards: updates now treat every notecard in the furniture as strictly off-limits. An update push can never remove or replace your `AVpos` (all poses and positions) or any other configuration notecard.
- **Fix**: The `RESERVE` setting from the `hudconfig` notecard (storage bytes kept free for your own scripts) is now actually honored when personal pose offsets are saved; it was silently ignored before. Existing furniture is converted automatically.
- **Feature**: Showcase mode for the Animesh dummies (owner only): switch `[SHOWCASE]` on in the seat list and the staged dummies stay put when you get up, which turns a staged pose into a store display. They also survive a visitor sitting down or swapping seats: the avatar visibly shares the seat instead of the display being torn down. Note that updating or resetting the furniture clears a staged display, so re-stage after an update.
- **Feature**: Bundled QuickySitter update, prop scale & worn fit: the new `[QS]objectadjust` companion script goes into your prop and makes it resizable from the editor, or fittable directly on the body for attachment props, and QuickySitter's `[SAVE]` persists it. End users can fine-tune a rezzed prop by touch (±1/5/10 % menu, `[RESTORE]`).
- **Fix**: Bundled QuickySitter update: the new "Adjust" access level lets chosen non-owners use the adjust tools (build from your personal account while a store account owns the furniture), the `[DUMP]` settings link works again on QuickySitter's own service, and its web page now shows the classic AVsitter layout.

## Version 1.24

- **Feature**: Animesh partner-dummy plugin is here (creator tool): set up couples / group poses without a second avatar. `[ADJUST]` → `[ANIMESH]` rezzes a posable dummy onto any empty seat of the current pose; position it through the HUD like a real partner. Click a dummy to change or remove it, even while adjusting.
- **Feature**: Eight standard dummy bodies included (Female / Male in S / M / L plus two Kabuki), auto-detected by name: drop any `[QS]dummy…` body into the furniture and it appears in the picker. The animeshconfig notecard is only needed for your own extra bodies.
- **Feature**: Animesh ships with the bundle: fresh installs, push installs and routine updates deliver the plugin and bodies automatically (creator builds only: finished customer furniture never receives it).
- **Feature**: `[FINALIZE]` strips the complete animesh kit (bodies, notecard, both scripts) off a finished furniture before you sell it.
- **Fix**: A repair update now refreshes the whole installation; previously it pushed only the missing pieces and silently skipped pending updates for everything already present (e.g. the HUD scripts).
- **Fix**: The installer no longer throws a script error when `[AV]sitA` is already deactivated (ItsNOTMine plate migration).

## Version 1.22

- **Base**: Foundation for the upcoming standalone Animesh plugin (solo setup of couples / group poses, no second avatar): 1.22 ships the QuickyHUD/QuickySitter integration base the plugin builds on, chiefly the hudproxy hook. The plugin itself is delivered separately later.
- **Fix**: Bundled QuickySitter update: the first sit after the furniture had been idle a while now plays the proper animation right away (in rare cases it could show the default pose until you re-sat).

## Version 1.21

- **Fix**: The HUD now works when QuickySitter is installed in a child prim, not only in the root/main prim.
